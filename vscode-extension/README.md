# 👻 Pocket Ghost

Pocket Ghost is a cozy coding companion that lives in your VS Code sidebar.

Meet **Wisp**, your tiny ghost who keeps you company, reacts to your interactions, and helps you stay focused while you work.

---

## ✨ Features

### 👻 Companion
- Animated ghost companion with subtle floating movement
- Blinking and ambient eye behavior
- Personality-driven dialogue
- Rename your ghost

### 🎮 Interactions
- Pet, feed, and play with Wisp
- Happiness and energy system
- Dynamic reactions

### ⏱️ Focus Mode
- Built-in focus timer (Pomodoro-style)
- Start, pause, resume, and complete sessions
- Tracks:
  - Focus time
  - Sessions
  - Streaks

### 🧠 Smart UI
- Responsive sidebar layout
- Compact mode for small sidebar widths
- Static fallback ghost for stability
